# LAN Voice + Video Chat

تطبيق اتصالات متكامل فائق السرعة مخصص للشبكات المحلية (**Local Area Network - LAN**) يتيح إجراء **مكالمات الفيديو (Video Calls)**، **المكالمات الصوتية (Voice Calls)**، والدردشة النصية المباشرة (فردية وجماعية)، بدون الحاجة لأي اتصال بالإنترنت أو خوادم سحابية (Cloud-free).

---

## 🌟 المميزات الرئيسية (Features)

1. **مكالمات فيديو محلية (LAN Video Calling)**:
   - اتصال مباشر من نظير إلى نظير (**WebRTC P2P**) بأعلى جودة وأقل تأخير زمني (Ultra-low Latency).
   - نافذة فيديو عائمة للمعاينة الذاتية (**Picture-in-Picture PIP**) مع مرآة طبيعية.
   - إمكانية تشغيل/إيقاف الكاميرا أثناء المكالمة مع استمرار الصوت دون انقطاع.
   - دعم ملء الشاشة (**Fullscreen**).
   - مؤقت مدة المكالمة المباشر (`00:00`) مع مؤشر جودة الاتصال.

2. **مكالمات صوتية متطورة (LAN Voice Calling)**:
   - مكالمات صوتية ثنائية مع أنيميشن نبضات الصوت المتفاعلة.
   - مكالمات جماعية خفيفة بنظام **Mesh WebRTC** لمجموعات العمل.
   - إمكانية كتم وإلغاء كتم الميكروفون بضغطة زر مع استمرار الفيديو.
   - كتم وإلغاء كتم مكبر الصوت.

3. **آلة حالات اتصال محكمة (Call State Machine)**:
   - إدارة دقيقة للحالات: `IDLE`, `CALLING`, `RINGING`, `ACCEPTED`, `CONNECTING`, `CONNECTED`, `REJECTED`, `BUSY`, `FAILED`, `ENDING`, `ENDED`.
   - منع تضارب المكالمات والرد التلقائي بحالة "مشغول" (`User Busy`) إذا كان الطرف الآخر في مكالمة قائمة.
   - معالجة الانقطاع المفاجئ وتنظيف المسارات وموارد الكاميرا والمايك فوراً.

4. **واجهة مستخدم احترافية وعصرية**:
   - تصميم زجاجي أنيق (**Glassmorphic Design**) متجاوب بالكامل مع شاشات الحواسيب، الأجهزة اللوحية، والهواتف الذكية.
   - دعم الوضعين **الليلي (Dark Obsidian)** و **النهاري (Crisp Light)** مع حفظ الخيار تلقائياً في المتصفح.
   - قائمة أجهزة متصلة ذكية تحتوي على أزرار اتصال سريع: **📞 صوت** و **🎥 فيديو**.

5. **اكتشاف الأجهزة المحلي (LAN Discovery)**:
   - مستجيب اكتشاف تلقائي عبر **UDP Broadcast** على المنفذ `37020` للتعرف على عنوان السيرفر بدون إدخاله يدوياً في الأدوات المساعدة.

6. **أمان وتحقق محلي (Security & Local SSL)**:
   - توليد شهادة HTTPS ذاتية التوقيع ديناميكياً عند الإقلاع لتضمين عنوان IP المحلي للجهاز، لضمان عمل أذونات المتصفح (`getUserMedia`) للكاميرا والميكروفون على جميع أجهزة الشبكة.

## 🛠️ المتطلبات (Requirements)

- **نظام التشغيل**: Windows, macOS, Linux, أو أندرويد (عبر Termux).
- **إصدار بايثون**: Python 3.10 أو أحدث.
- **العتاد (Hardware)**:
  - كاميرا وميكروفون متصلان بالأجهزة الراغبة بإجراء المكالمات.
- **الشبكة**:
  - شبكة محلية مشتركة (نفس راوتر الـ Wi-Fi أو سويتش LAN).
- **المتصفحات المدعومة**:
  - Google Chrome, Microsoft Edge, Mozilla Firefox, Safari.

## 📦 التثبيت (Installation)

1. افتح موجه الأوامر أو الطرفية في مجلد المشروع:
   ```bash
   cd LAN-VOICE-CHAT
   ```

2. تثبيت الحزم المطلوبة من `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```

> **ملاحظة بخصوص المكتبات:** المشروع يعتمد على مكتبات بايثون القياسية وخادم FastAPI/Uvicorn، ولا يتطلب OpenCV أو FFmpeg، حيث تتولى محركات المتصفحات الأصلية معالجة وتدفق WebRTC بكفاءة عالية واستهلاك منخفض جداً للمعالج والذاكرة.

## 🏛️ معمارية المشروع (MVC Architecture)

تمت إعادة هيكلة المشروع وفق معمارية **Model-View-Controller (MVC)** المتوافقة مع تطبيقات الويب الحديثة (FastAPI + SPA):

```text
LAN-VOICE-CHAT/
│
├── backend/
│   ├── models/                   # [M - Models]
│   │   ├── schemas.py            # نماذج Pydantic للتحقق من البيانات
│   │   └── database.py           # طبقة الوصول لقاعدة البيانات SQLite
│   │
│   ├── controllers/              # [C - Controllers]
│   │   ├── auth_controller.py    # مسارات المصادقة والتسجيل
│   │   ├── users_controller.py   # مسارات المستخدمين والرسائل الخاصة
│   │   ├── groups_controller.py  # مسارات المجموعات والمحادثات الجماعية
│   │   ├── calls_controller.py   # مسارات استعلام سجل المكالمات
│   │   └── ws_controller.py      # متحكم WebSocket وإشارات WebRTC
│   │
│   ├── services/                 # [Services / Business Logic]
│   │   ├── call_manager.py       # إدارة آلة حالات المكالمات الثنائية
│   │   ├── group_call_manager.py # إدارة المكالمات الجماعية
│   │   ├── connection_manager.py # إدارة اتصالات المقابس النشطة
│   │   ├── auth_service.py       # خدمات التشفير والتوكنات
│   │   ├── certs_service.py      # توليد شهادات SSL ديناميكياً
│   │   └── discovery_service.py  # خدمة الاكتشاف UDP Broadcast
│   │
│   ├── main.py                   # تجميع التطبيق وتسجيل المتحكمات
│   └── run.py                    # نقطة الانطلاق الأساسية (HTTPS Runner)
│
├── views/                        # [V - Views] طبقة العرض وواجهة المستخدم (SPA مع معمارية MVC في العميل)
│   ├── index.html                # صفحة العرض الرئيسية
│   ├── style.css                 # تصميم الواجهة وأنظمة الألوان (Dark/Light)
│   └── app.js                    # منطق العميل المُنظَّم كمعمارية MVC (Models, Views, Controllers)
│
├── requirements.txt
└── README.md
```

## 🚀 التشغيل (Running)

لتشغيل السيرفر مع تفعيل HTTPS تلقائياً (وهو الوضع المطلوب لعمل الكاميرا والميكروفون من مختلف أجهزة الشبكة):

```bash
cd backend
python run.py
```

ستظهر لك رسالة في الطرفية تحتوي على الروابط:
```text
============================================================
  LAN Voice Chat — HTTPS
  من نفس الجهاز:      https://127.0.0.1:8443
  من أجهزة الشبكة:    https://192.168.1.X:8443
============================================================
```

## 🌐 إعداد الاتصال بين جهازين على نفس الشبكة (LAN Setup)

```text
       ┌──────────────┐                  ┌──────────────┐
       │   الجهاز A   │                  │   الجهاز B   │
       │ (سيرفر + مستخدم)                 │   (مستخدم)   │
       └──────┬───────┘                  └──────┬───────┘
              │                                 │
              └──────────────► Wi-Fi ◄──────────┘
                              Router
                                │
                      (لا حاجة لإنترنت)
```

1. **الجهاز الأول (سيرفر + متصل)**:
   - يقوم بتشغيل الخادم عبر `python run.py`.
   - يفتح المتصفح على الرابط: `https://127.0.0.1:8443` (أو `https://192.168.1.X:8443`).
   - ينشئ حساباً (مثلاً: `Ahmed`).

2. **الجهاز الثاني (متصل عبر الشبكة)**:
   - يتصل بنفس شبكة الـ Wi-Fi.
   - يفتح المتصفح على رابط جهاز السيرفر: `https://192.168.1.X:8443`.
   - يتجاوز تحذير الشهادة الذاتية لمرة واحدة (تفاصيل بالأسفل).
   - ينشئ حساباً آخر (مثلاً: `Mohammed`).

3. يظهر كل جهاز فوراً في قائمة "الأجهزة المتصلة" لدى الآخر مع أزرار الاتصال الصوتي 📞 والمرئي 🎥.

## 🔒 تجاوز تحذير الشهادة الذاتية (Self-Signed SSL)

نظراً لأن الشهادة مولدة محلياً بدون خادم مصادقة خارجي، سيُظهر المتصفح تحذيراً لمرة واحدة فقط عند الدخول من جهاز جديد:
- **Chrome / Edge**: اضغط على **خيارات متقدمة (Advanced)** ثم **المتابعة إلى الموقع (غير آمن) / Proceed to ... (unsafe)**.
- **Safari**: اضغط على **إظهار التفاصيل (Show Details)** ثم **زيارة هذا الموقع (visit this website)**.
- **Firefox**: اضغط على **خيارات متقدمة (Advanced)** ثم **قبول المخاطرة والمتابعة (Accept the Risk and Continue)**.

## 🛡️ إعدادات جدار الحماية والمنافذ (Firewall & Ports)

تأكد من سماح جدار الحماية (Windows Firewall أو iptables) على جهاز السيرفر بالمنافذ التالية:
- **`8443` (TCP)**: منفذ خدمة الويب وواجهة WebSocket وHTTPS الأساسي.
- **`37020` (UDP)**: منفذ خدمة اكتشاف السيرفر المحلي التلقائي (Broadcast).
- منافذ الـ WebRTC الداخلية: يتم فتحها تلقائياً ديناميكياً بين المتصفحين ضمن نطاق الشبكة المحلية.
